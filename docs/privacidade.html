Política de Privacidade

Última atualização: 13 de novembro de 2026.

O vicenix autopost é uma ferramenta de uso exclusivo do dono dos canais vicenix. Ela é usada apenas por ele, nas próprias contas.

Quais dados são acessados

Apenas a permissão de enviar vídeos ao próprio canal do YouTube (escopo youtube.upload) e de publicar no próprio perfil do Instagram. Nenhum dado de outros usuários é lido, coletado ou armazenado.

Como os dados são usados

As credenciais servem só para publicar os vídeos agendados pelo dono. Elas ficam guardadas de forma criptografada (GitHub Secrets) e nunca são compartilhadas, vendidas ou usadas para outro fim.

Uso de dados das APIs do Google

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. O uso das APIs do YouTube também segue os Termos de Serviço do YouTube e a Política de Privacidade do Google.

Como revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
